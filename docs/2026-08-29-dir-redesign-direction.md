# DIR redesign direction

## Chosen world

**The attention proof** — a task app built like a variable type specimen: each thought gets one clean line, the next action gets the largest scale, and controls change the work directly. The physical reference is a print-room proof sheet: ink, paper, crop marks, and a clear reading order.

The category default is the backlog dashboard made of equally weighted cards. This direction refuses that arrangement. DIR should make a person feel that the next mark is manageable before it asks them to manage the whole list.

## First surface

Inbox opens with a `NEXT MARK` panel for one task, a direct `Start 25 min` / `Done` pair, and an inline “put it somewhere safe” capture line. The rest of the inbox is a quiet proof list below. Empty state says what to do next instead of celebrating zero.

## System grammar

- Near-white paper and ink black are the field; DIR terracotta is the foundry accent.
- Large, confident task titles carry hierarchy. Small mono labels carry dates, estimates, and state.
- A 1px rule separates proof lines; elevation is reserved for the one active panel and transient feedback.
- Tasks are never decorated into cards-within-cards. The structure is one active proof, one capture line, then a readable list.
- Motion is limited to completion removal and one focused press response. Reduced motion remains calm.

## ADHD-friendly interaction

- Capture can happen without opening a second screen.
- The primary screen offers one obvious next move, not an optimized ranking or a score.
- “More details” is progressive disclosure in Quick Add.
- The user can finish from the list and undo immediately.
- Timeboxes are concrete and small; urgency never becomes shame.
